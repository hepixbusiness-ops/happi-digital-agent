# Captures des réalisations

Déposez ici les captures d'écran des sites clients. La page `realisations.html`
les charge automatiquement. Si un fichier est absent, la vignette dégradée avec
les initiales s'affiche à la place : rien ne casse.

| Fichier | Contenu attendu | Format conseillé |
|---|---|---|
| `sapres-desktop.jpg` | Accueil sapressarl.com sur ordinateur | 1600 x 1000 px, cadrage haut de page |
| `sapres-mobile.jpg` | Accueil sapressarl.com sur téléphone | 420 x 900 px |
| `net-desktop.jpg` | Accueil newenergytechnology.sarl sur ordinateur | 1600 x 1000 px |
| `net-mobile.jpg` | Accueil newenergytechnology.sarl sur téléphone | 420 x 900 px |

Compressez les images avant de les pousser (viser moins de 250 Ko par capture)
pour rester rapide sur les connexions mobiles camerounaises.
